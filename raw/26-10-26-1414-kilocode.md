GitHub front page of the Kilo-Org/kilocode repository. The README presents Kilo Code as an open source coding agent usable in VS Code, JetBrains or a CLI, with a choice of 500+ models billed at the provider's rate. It names four built-in agents (Code, Plan, Ask, Debug) plus custom agents, and lists features such as inline autocomplete, terminal and browser control, a marketplace for skills and MCP servers, a cloud agent and automated code reviews. The sidebar shows the MIT licence, about 27.8k stars and 3.3k forks.
