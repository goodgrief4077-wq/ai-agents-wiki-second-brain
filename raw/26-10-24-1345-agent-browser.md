README of vercel-labs/agent-browser. It presents a browser automation CLI for AI agents built as a native Rust binary that drives Chrome over CDP, using Chrome for Testing by default and detecting existing Chrome, Brave, Playwright or Puppeteer installs; the daemon needs neither Playwright nor Node.js. Install routes listed are a global npm package, Homebrew and Cargo, plus building from source with Node.js 24+, pnpm 11+ and Rust. The core workflow is an accessibility-tree snapshot that labels elements with short refs which later commands act on. The README states that page-provided WebMCP names, descriptions, schemas and results are untrusted data.
