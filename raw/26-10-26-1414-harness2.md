GitHub front page of the google-research/harness2 repository (about 19.8k stars, 1.9k forks, 3 commits at retrieval). The README defines a harness as the system around a model (prompts, tools, memory, skills, orchestration) and presents Harness2 as a framework for recursive agent harnessing with fixed model weights. It describes task-level recursion (propose, probe, compose) and harnessing-level recursion, eight editable harness components, OpenCode and Codex executors, and three benchmarks. Setup needs Linux, Python 3.12 and uv, and model-backed runs use Vertex AI and incur API costs.
