GitHub front page of the andrewyng/openworker repository. The README presents OpenWorker as an open-source, local-first desktop AI coworker in open beta that delivers finished work (documents, reviewed code, triaged inboxes) rather than chat. It describes a native desktop shell over a local Python agent server built on aisuite, bring-your-own-key access to many model providers plus local runtimes such as Ollama, 25+ connectors and MCP support, and scheduled automations. A "Governed by design" section describes four tiers: hard floors, a ladder of earned autonomy, an audit trail with approval provenance, and an optional sandbox. Security coworkers are the first specialist coworkers. The download section lists macOS (Apple Silicon) and Windows builds only, and run-from-source needs Python, Node and the Rust toolchain.
