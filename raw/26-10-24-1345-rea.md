README of morluto/rea (REA, Reverse Engineer Anything). It describes one MCP server, plus a CLI with the same workflows, for reverse engineering binaries, applications and runtime behaviour; the agent calls it and gets findings back with evidence. Setup is an interactive command that registers the MCP server and workflow instructions with agents such as Claude Code, Codex, Cursor and Gemini CLI, backing up existing config. A terminal example analyses an extracted JavaScript or Electron app directory or ASAR and returns modules, imports and Electron boundaries. Native binary analysis needs Hopper, Ghidra or IDA; other targets (Go binaries, GPU code objects, model files, IL2CPP metadata, Godot packs) use built-in static inspection. It requires recent Node.js 22, 24 or 26 releases, and the README warns that only morluto/rea, rea.tools and the rea-agents package are official sources.
