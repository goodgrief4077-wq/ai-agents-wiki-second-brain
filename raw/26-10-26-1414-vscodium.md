GitHub front page of the VSCodium/vscodium repository. The README says it is not a fork but a set of scripts that build Microsoft's vscode repository into freely-licensed binaries with a community-driven default configuration, and it explains the project exists because Microsoft's own builds carry a non-free licence and telemetry. It lists install routes for macOS, Windows and Linux. The sidebar shows the MIT licence, about 33.8k stars and 1.9k forks.
