Codex CLI is a lightweight coding agent from OpenAI that runs locally in your terminal (Apache-2.0).

## What it does
Runs on your own computer as a coding agent. Sign in with a ChatGPT plan (Plus, Pro, Business, Edu or Enterprise) or use an API key. Install through a standalone installer script, npm (`@openai/codex`) or Homebrew (`brew install --cask codex`). The README also points to a desktop app (`codex app`), editor integration (VS Code, Cursor, Windsurf), and a separate cloud agent, Codex Web, at chatgpt.com/codex.
