Kilo Code is an open source (MIT) coding agent that runs in VS Code, JetBrains IDEs or a command-line interface. Compare [[pi-coding-agent]] and [[codex]].

## What it does
The README says users choose among 500+ models, can switch mid-task, and pay the model provider's rate. It names four built-in agents (Code, Plan, Ask, Debug) plus custom agents, and lists multi-file code generation, inline autocomplete, self-checking, terminal and browser control, and a marketplace for agents, skills, MCP servers and plugins. A cloud agent and automated pull-request code reviews are also described. The CLI installs through npm, pnpm, bun, Homebrew, the AUR or a script, and runs with the `kilo` command.
