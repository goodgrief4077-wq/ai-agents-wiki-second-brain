VSCodium is a community project that builds Microsoft's vscode source into freely-licensed binaries, as an alternative to Microsoft's own branded distribution. See [[vs-code]] for the upstream editor.

## What it does
The README says it is not a fork but a repository of scripts that build the vscode repository with a community-driven default configuration. It gives the reason as Microsoft's own builds carrying a non-free licence and telemetry. It lists install routes through Homebrew, WinGet, Chocolatey, Scoop, snap, Linux package repositories, the AUR and Flatpak, and downloads for stable and insiders builds. The latest release tracks an upstream VS Code version (1.140.0 at retrieval).
